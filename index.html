Independent Software Lab

We Build Software
That Answers To You.

The Brink Labs is an independent software lab. We build tools that run on your own device, keep your data where you put it, and are bought once rather than rented forever. Everything below is either shipped or not mentioned.

The Doctrine

Four Commitments,
Written As Constraints.

A principle you can break at will is a preference. These four are written into the architecture, which is what makes them checkable rather than reassuring.

01

On-device by default

If a feature can run on the phone, it runs on the phone. The network is a privilege we ask permission for, never an assumption we design around. This is why there is no sync — a copy you cannot see is still a copy.

02

Bought once, owned forever

A tool you open daily makes an excellent subscription and a poor deal. We charge once. If the company disappears tomorrow the software keeps working, because nothing about it depends on us still being here.

03

No advertising, no telemetry

There is no analytics SDK, no attribution SDK and no crash reporter phoning home. We do not know how many screens you opened today, and we have built ourselves no way of finding out.

04

Correct before clever

Arithmetic about somebody’s money is not a place for approximately. Every figure is checked against an independent implementation before it ships, and a feature waits if the maths is not settled.

A privacy policy is a promise about what a company will choose to do.
An architecture is a statement about what is possible.

MyneWallet
Android · Live on Google Play

A budget planner and expense tracker that never asks for a bank login, never sends your ledger anywhere, and keeps working in airplane mode — because there is nowhere for it to phone.

  • Zero-based envelope budgeting — every unit of income assigned before it is spent.
  • Two-tap capture — no network round-trip between spending and logging.
  • An analysis engine, not a pie chart — net worth, obligations and a 30-day outlook.
  • AES-256 backups to your own Google Drive, encrypted before they leave the phone.

Engineering Standard

Tested Like Infrastructure,
Not Like An App.

Personal finance software fails quietly. A wrong figure looks exactly like a right one, so the only defence is refusing to trust the first implementation of anything.

1,100+
Automated tests on every MyneWallet release, covering the arithmetic, the entitlement caps and the import engine.
2×
Every instrument’s maths is verified against a second, independently written implementation before it ships.
0
Third-party SDKs in the app. No advertising, no attribution, no analytics, no crash reporter.
100
Lighthouse accessibility on every page of this site, with contrast solved against the tinted surfaces, not just the flat ones.

We publish the failures too. The build report for this site lists eight defects found and fixed in the last pass, including two that had been live for weeks — because a standard nobody can audit is a slogan.

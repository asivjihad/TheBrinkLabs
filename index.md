The Doctrine

## Four Laws. Every Product. No Exceptions.

Not marketing positions — build constraints. When a feature request arrives, one of these decides the answer before anyone opens an editor.

### On-Device By Default

If a feature can run on the phone, it runs on the phone. The network is a privilege we ask permission for, never an assumption we design on top of. Software that needs a server needs a company to keep paying for that server — and that is how software dies.

### Owned, Not Rented

You pay once. The software is then yours — through reinstalls, new phones, and every update we ever ship. No renewal can take it away, because there is no renewal. We would rather earn a purchase than trap a payment.

### Zero Telemetry

No advertising SDK. No product analytics. No crash pipeline. We find out whether something works by asking people, the way you are supposed to. A breach of our infrastructure cannot expose you, because no infrastructure of ours is holding you.

### Correctness Before Cleverness

Money is stored as integers, never floating point. Every write is atomic. Liabilities carry an explicit sign convention. A number that looks right and is wrong is worse than no number at all, so we test the arithmetic harder than we test the animation.
Three business models aim at the user. There is a fourth: you sell the software.

The Engineering Standard

## Boring, Ruthless, Auditable.

Privacy-first software spent a decade being excused for being worse. We refuse the excuse. The constraint is the design brief, not the apology.
- Integer money, end to end. Every amount stored in minor units. No float ever touches a balance, so cents cannot drift.
- Atomic writes. A transaction, its ledger entry and its balance effect land in one database transaction, or none of them do.
- A frame budget, enforced. 60fps is a requirement in review, not a hope.
- Tested like infrastructure. Every MyneWallet release ships against 1,100+ automated tests covering the arithmetic, the entitlement caps and the import engine.
- Your data walks out with you. Full CSV export and PDF statements in every product that holds data. No lock-in, because there is nothing to lock you into.
